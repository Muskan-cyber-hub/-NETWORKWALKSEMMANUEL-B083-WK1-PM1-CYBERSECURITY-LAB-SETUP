# -NETWORKWALKSEMMANUEL-B083-WK1-PM1-CYBERSECURITY-LAB-SETUP
This repository documents the NetworkWalks Emmanuel B083 WK1 PM1 Cybersecurity Lab Setup project. It focuses on creating a practical cybersecurity environment to understand networking fundamentals, explore security tools, and develop essential technical skills through hands-on learning. # 💫 About Me:
This repository documents the setup and configuration of a cybersecurity lab environment as part of the Network Walkthroughs B083 – Week 1, Practical Module 1. It covers the initial installation and configuration of virtualization software, virtual machine setup, and network configuration using NAT Network mode. The lab provides hands-on experience with virtualized environments, basic networking concepts, and cybersecurity lab preparation. It demonstrates the fundamental steps required to establish an isolated and controlled environment for practicing cybersecurity techniques, network analysis, and security testing. This project serves as a practical learning resource for understanding virtual machines, network connectivity, and essential cybersecurity lab infrastructure.
